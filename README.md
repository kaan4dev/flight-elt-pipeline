# flight-elt-pipeline

## Overview

This repository contains an ELT (Extract, Load, Transform) pipeline focused on flight data. Built primarily with Python, it offers a modular and scalable approach to ingesting, storing, and transforming flight-related datasets for analytics and reporting.

## Features

- **Extraction:** Supports multiple data sources (APIs, CSV, databases).
- **Loading:** Efficiently loads raw data into target storage (e.g., databases, cloud storage).
- **Transformation:** Cleans and structures flight data for downstream analysis.
- **Extensibility:** Easy to add new data sources or transformation steps.

## Technologies Used

- **Python:** Core language for pipeline orchestration and data processing.
- **Jupyter Notebook:** For exploratory analysis and prototyping.
- **HTML:** Used for reporting or documentation purposes.
